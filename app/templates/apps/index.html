Installing on a phone

  1. Open this page on the phone - sign in, or scan the code with the phone's camera.
  2. Tap Download. When the phone asks, allow your browser to install apps (Install unknown apps).
  3. Open the downloaded file and tap Install.
    4. {% set keys = cards|map(attribute='app.key')|list %}
